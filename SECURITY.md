# Security Policy

## Supported Versions

The current `main` branch and the latest published Fluxzero CLI release receive
security fixes. Older releases are not supported; update to the latest release
before reporting when possible.

## Reporting a Vulnerability

Report suspected vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/fluxzero-io/fluxzero-cli/security/advisories/new).
Do not open a public issue or pull request for a vulnerability that has not yet
been disclosed.

Include the affected version and platform, the expected impact, and steps or a
minimal example that reproduce the issue. We will use the private advisory to
coordinate triage, remediation, and disclosure with you.
